# Legacy Python version (0.8.x)

CcooNverter up to v0.8.7 was a Python application (CustomTkinter GUI, rawpy/LibRaw for RAW development, PyInstaller Windows exe). Those builds remain downloadable from the v0.8.x entries on the [GitHub Releases](https://github.com/marushin/CcoonVerter/releases) page. The Python source is **not** part of this repository: it lives in the author's local project folder and served only as the behavioural reference for the Rust rewrite (v0.9.0 and later); see `docs/01_PROJECT_REVIEW.md` and `docs/02_RUST_PORTING_PLAN.md` for how features map between the two versions. Settings and presets written by 0.8.x (`converter_settings.json`, `presets.json` next to the exe) are imported automatically by 0.9.0 on first start when the new executable is placed in the same folder.

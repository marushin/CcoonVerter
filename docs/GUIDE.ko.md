# CcooNverter 사용 안내

CcooNverter는 RAW 사진을 폴더째로 JPG, PNG, TIFF, WebP로 바꿔 주는 프로그램입니다. 사진 관리나 부분 보정은 하지 않습니다. 폴더를 고르고, 결과를 미리 본 다음, 버튼 하나로 변환합니다.

이 안내는 이 프로그램을 처음 보는 사진가를 위해 썼습니다. 궁금한 점은 [자주 묻는 질문](FAQ.ko.md)에도 정리해 두었습니다. English: [GUIDE.en.md](GUIDE.en.md)

![메인 화면](screenshots/gui_windows_ko.png)

## 1. 설치

[Releases](https://github.com/marushin/CcoonVerter/releases/latest) 페이지에서 내 컴퓨터에 맞는 파일을 받으세요.

| 운영체제 | 파일 | 설치 방법 |
|---|---|---|
| Windows 10/11 (64비트) | `CcooNverter_v1.0.0_windows_x64.exe` | 설치 과정이 없습니다. 받은 파일을 원하는 폴더에 두고 실행합니다. |
| macOS 11 이상 (Apple Silicon, Intel) | `CcooNverter_v1.0.0_macos_universal.dmg` | DMG를 열고 `CcooNverter.app`을 Applications 폴더로 끌어다 놓습니다. |

### 처음 실행할 때 나오는 경고

처음 실행하면 Windows나 macOS가 경고를 띄웁니다. **이 프로그램에는 아직 유료 코드 서명이 없기 때문입니다.** 코드 서명은 "이 파일을 누가 만들었는지"를 운영체제 제작사의 인증서로 보증하는 절차입니다. 서명이 없다고 해서 바이러스라는 뜻은 아니지만, 운영체제 입장에서는 만든 사람을 확인할 수 없으므로 경고가 나오는 것이 정상입니다.

믿을 수 있는지는 직접 판단해 주세요. 공식 배포처는 위 Releases 페이지뿐이며, 함께 올라오는 `SHA256SUMS.txt`로 파일이 바뀌지 않았는지 확인할 수 있습니다. 소스 코드도 전부 공개되어 있습니다.

**Windows (SmartScreen)**

"Windows의 PC 보호" 파란 창이 뜨면:

1. **추가 정보**를 누릅니다.
2. 아래에 나타나는 **실행**을 누릅니다.

한 번 허용하면 같은 파일에서는 다시 묻지 않습니다.

**macOS (Gatekeeper)**

"확인되지 않은 개발자", "Apple에서 확인할 수 없습니다" 같은 창이 뜨면 일단 **취소**하고 다음 중 하나를 따르세요.

- macOS 15(Sequoia) 이상: **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 맨 아래쪽 보안 항목의 **그래도 열기**를 누릅니다. 이후 암호를 입력하면 열립니다.
- macOS 14 이하: Finder에서 `CcooNverter.app`을 **Control-클릭(또는 우클릭) → 열기 → 열기**.
- 위 방법이 통하지 않거나 "손상되었기 때문에 열 수 없습니다"라고 나오면 터미널에서 아래 한 줄을 실행합니다. 인터넷에서 받은 파일에 붙는 격리 표시를 지우는 명령입니다.

  ```bash
  xattr -dr com.apple.quarantine /Applications/CcooNverter.app
  ```

이 안내의 macOS 부분은 Windows 개발 환경에서 쓴 것으로, 위 절차를 macOS에서 직접 실행해 확인하지는 못했습니다.

### 앱 언어

첫 실행 때 시스템 언어를 따라 한국어 또는 영어로 나옵니다. 왼쪽 아래 **앱** 영역에서 바꿀 수 있습니다.

## 2. 첫 변환

**1단계. 폴더를 고릅니다.** RAW 파일이 든 폴더를 창에 끌어다 놓거나, 위쪽 **찾아보기**로 고릅니다. 하위 폴더까지 함께 변환됩니다. 특정 RAW 파일 몇 장만 변환하려면 그 파일들을 창에 끌어다 놓으세요.

![빈 화면](screenshots/empty_ko.png)

**2단계. 미리 봅니다.** 가운데에 첫 사진이 현상되어 나타납니다. 위쪽의 `<`, `>`로 다른 사진을 볼 수 있습니다.

**3단계. 버튼을 누릅니다.** 오른쪽 아래 **맛있게 구워볼까요!** 버튼을 누릅니다. 진행률과 남은 시간이 표시되고, 끝나면 결과 카드가 나타납니다.

결과는 저장 폴더를 지정하지 않으면 **RAW 폴더 안의 `Converted_JPG` 폴더**에 저장됩니다. 하위 폴더 구조는 그대로 유지되고, RAW 원본은 건드리지 않습니다.

## 3. RAW 현상과 카메라 JPEG

왼쪽 맨 위의 두 버튼으로 방식을 고릅니다.

| | **RAW 현상** | **카메라 JPEG** |
|---|---|---|
| 하는 일 | RAW 데이터를 직접 현상합니다. | 카메라가 RAW 안에 넣어 둔 JPEG을 꺼냅니다. |
| 조정(노출, 스타일 등) | 적용됩니다. | 적용되지 않습니다. 화면에서도 숨겨집니다. |
| 속도 | 상대적으로 느립니다. | 가장 빠릅니다. |
| 결과 | JPEG, PNG, 16비트 TIFF, WebP 중 선택 | 항상 JPEG |
| 지원하지 않는 카메라 | 실패로 표시됩니다. | 대부분 그대로 동작합니다. |

**카메라 JPEG**을 쓰면서 긴 변을 지정하지 않으면 카메라가 만든 JPEG 화상 데이터를 다시 압축하지 않고 그대로 저장합니다. 화질 손실이 없습니다. 긴 변을 지정하면 크기를 줄이기 위해 다시 압축합니다. 파일 안에 카메라 JPEG이 없으면 RAW를 대신 현상하고, 결과 카드에 알려 줍니다.

언제 무엇을 쓰면 좋을까요? 카메라에서 찍은 색 그대로 빠르게 공유하고 싶다면 카메라 JPEG, 색과 밝기를 조정하거나 큰 파일로 후보정하려면 RAW 현상이 맞습니다.

## 4. 조정과 스타일

RAW 현상 모드에서만 보입니다. 값을 바꾸면 미리보기가 바로 다시 그려집니다.

- **노출 (EV)**: 사진 전체의 밝기입니다. +1은 빛이 두 배입니다. 프로그램은 자동으로 카메라 JPEG 밝기에 맞춰 시작점을 잡으므로, 대개 0에서 시작하면 됩니다.
- **화이트 밸런스**: *카메라 기본값*은 촬영 당시 설정을, *자동*은 사진에서 추정한 값을 씁니다.
- **톤 커브**: 카메라 JPEG처럼 부드럽게 대비를 주는 곡선입니다. 끄면 평평한 결과가 나옵니다.
- **스타일**: 12가지 썸네일에서 고릅니다. 썸네일은 지금 보고 있는 사진으로 그린 실제 결과입니다.
- **고급**: 접혀 있는 항목을 누르면 RGB 균형과 블랙/화이트 포인트(레벨)가 나옵니다. 예전 프리셋의 밝기 값을 쓰고 있으면 여기에 함께 표시됩니다.
- **초기화**: RAW 조정값만 기본값으로 돌립니다. 크기, 품질, EXIF 같은 출력 설정은 그대로입니다.

슬라이더를 **더블클릭**하면 그 값만 기본값으로 돌아갑니다.

![고급](screenshots/advanced_ko.png)

## 5. 미리보기 도구

미리보기는 저장할 파일과 같은 계산을 거칩니다. 화면에서 본 결과가 저장되는 결과입니다.

- **맞춤 / 100%**: 맞춤은 사진 전체, 100%는 원본의 실제 픽셀을 보여 줍니다. 사진을 더블클릭해도 전환됩니다. 100%에서는 드래그로 이동합니다. 큰 RAW는 100%로 처음 들어갈 때 몇 초 걸릴 수 있습니다.
- **비교**: 왼쪽은 카메라 JPEG, 오른쪽은 현상 결과입니다. 경계선을 드래그해 위치를 옮깁니다. 파일 안에 카메라 JPEG이 있을 때만 쓸 수 있습니다.
- **히스토그램**: 오른쪽 위에 밝기 분포를 표시합니다. 버튼으로 켜고 끕니다.

![비교](screenshots/split_ko.png)

창이 좁으면 미리보기는 **미리보기 표시** 버튼으로 펼칩니다. 변환이 진행되는 동안 미리보기는 잠시 멈춥니다.

## 6. 출력 옵션

왼쪽 **출력** 영역에서 정합니다.

- **긴 변 (px)**: 결과 사진의 긴 변 픽셀 수입니다. 비워 두면 **원본 크기** 그대로입니다. 원본보다 큰 값을 넣어도 크게 늘리지는 않습니다.
- **품질**: JPEG과 WebP에만 적용됩니다. 보통 90이면 충분합니다.
- **촬영 정보(EXIF) 유지**: 카메라, 렌즈, 노출, 촬영 일시, GPS, 별점을 파일에 있는 만큼 결과 파일에 옮깁니다. **기본으로 켜져 있습니다.** 위치 정보까지 함께 옮겨지므로, 웹에 올리기 전 위치 정보 등을 지우고 싶으면 이 옵션을 끄세요.
- **원본 파일 날짜 유지**: 결과 파일의 수정 날짜를 RAW 파일과 같게 맞춥니다.
- **이미 있으면**: 같은 이름의 결과 파일이 있을 때 *접미사 붙이기*(`이름_arw.jpg`처럼 새로 저장), *건너뛰기*, *덮어쓰기* 중에 고릅니다.

**형식** 버튼을 누르면 자세한 창이 열립니다.

![출력 옵션](screenshots/output_ko.png)

| 형식 | 특징 |
|---|---|
| JPEG | 8비트. 파일이 작고 어디서나 열립니다. |
| PNG | 8비트 무손실. 파일이 큽니다. |
| TIFF 16비트 | 채널당 16비트, 비압축. 추가 보정용이며 매우 큽니다. |
| WebP | 8비트 손실 압축. JPEG보다 작습니다. 한 변 최대 16383픽셀. |

**색 공간**은 대부분 *sRGB*로 두면 됩니다. *AdobeRGB*는 인쇄 작업용이지만 한계가 있습니다([FAQ](FAQ.ko.md#adobergb로-저장하면-색이-더-넓어지나요)).

**파일 이름**에는 다음 항목을 넣을 수 있습니다. 예를 들어 `{date}_{name}`은 `2026-11-09_IMG_1234.jpg`가 됩니다. 창 안의 예시로 결과를 바로 확인할 수 있습니다.

| 항목 | 뜻 |
|---|---|
| `{name}` | 원본 파일 이름 (기본값) |
| `{date}` | 촬영일 `YYYY-MM-DD`. 없으면 파일 날짜 |
| `{time}` | 촬영 시각 `HHMMSS` |
| `{seq}` | 일련번호 `0001`부터 |
| `{camera}` | 카메라 모델 |
| `{ext}` | 원본 확장자 |

## 7. 프리셋

자주 쓰는 설정을 이름 붙여 저장합니다. 왼쪽 아래 **프리셋**에서 **저장**을 눌러 이름을 넣고, 다음부터는 목록에서 고르면 저장해 둔 값이 모두 적용됩니다. 다만 "이미 있으면" 항목은 프리셋이 바꾸지 않습니다.

Python 버전(v0.8.x)에서 쓰던 프리셋도 읽을 수 있습니다.

## 8. 결과 카드 읽기

변환이 끝나면 미리보기 자리에 결과 카드가 나타납니다.

![결과 카드](screenshots/result_ko.png)

- **완료**: 저장에 성공한 파일 수.
- **건너뜀**: "이미 있으면: 건너뛰기"로 저장하지 않은 파일 수.
- **실패**: 변환하지 못한 파일 수. 파일 이름과 이유가 아래에 나옵니다.

실패 이유의 뜻은 다음과 같습니다.

| 카드에 나오는 말 | 뜻 | 할 수 있는 일 |
|---|---|---|
| 이 카메라는 아직 RAW 현상을 지원하지 않습니다 | 디코더가 이 카메라를 모릅니다. | 카메라 JPEG 모드로 JPEG을 꺼낼 수 있습니다. |
| 이 RAW 압축 방식은 아직 현상할 수 없습니다 | Nikon High Efficiency 같은 압축입니다. | 위와 같습니다. |
| 파일이 손상되었거나 이 앱이 읽을 수 없는 RAW 파일입니다 | 파일이 깨졌거나 RAW가 아닙니다. | 다른 프로그램으로도 열리는지 확인해 보세요. |
| 파일을 읽거나 쓰지 못했습니다 | 디스크가 가득 찼거나 권한이 없습니다. | 저장 위치를 확인하세요. |

**폴더 열기**는 결과 폴더를 엽니다. **닫기**를 누르면 미리보기로 돌아갑니다. 일부 파일이 실패하면 자세한 내용이 담긴 로그 파일의 위치도 함께 나옵니다.

## 9. 설정과 로그가 있는 곳

프로그램을 닫을 때 설정이 자동 저장되고, 다음에 켜면 마지막 폴더와 설정으로 시작합니다.

| 운영체제 | 설정, 프리셋 | 로그 |
|---|---|---|
| Windows | `%APPDATA%\ccoon\CcooNverter\config\` | `%LOCALAPPDATA%\ccoon\CcooNverter\data\logs\ccoonverter.log` |
| macOS | `~/Library/Application Support/ccoon.CcooNverter/` | `~/Library/Application Support/ccoon.CcooNverter/logs/ccoonverter.log` |

`settings.json`이 설정, `presets.json`이 프리셋입니다. 문제를 알릴 때 로그 파일을 함께 보내 주시면 원인을 찾는 데 도움이 됩니다. 프로그램을 지울 때는 실행 파일과 위 폴더를 지우면 됩니다.

인터넷 연결은 **새 버전 확인** 한 가지에만 씁니다(GitHub, 하루 한 번까지). 사진이나 사용 기록은 어디로도 보내지 않습니다. 왼쪽 아래 **앱** 영역의 체크박스로 끌 수 있습니다.
